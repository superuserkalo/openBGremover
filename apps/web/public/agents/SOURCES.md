# Agent logo sources

Retrieved 14 October 2026. Logos identify their respective products.

- Pi: https://pi.dev/logo-auto.svg, linked from https://pi.dev/. Original coral
  `#F09082`, blue `#4D9ABF`, and gold `#F1BE58` fills. ViewBox trimmed to the mark's
  bounds for legibility at menu-icon size. Path geometry is unchanged.
- OpenCode: `opencode-logo-light.svg`, downloaded from https://opencode.ai/brand.
  Original charcoal `#211E1E` and gray `#CFCECD` fills and geometry, unchanged.
- Claude: https://unpkg.com/@lobehub/icons-static-svg@latest/icons/claude-color.svg.
  Color variant from the same MIT-licensed library used for Cursor and OpenAI.
- Cursor and OpenAI: Lobe Icons SVG assets. See LICENSE in this directory.
